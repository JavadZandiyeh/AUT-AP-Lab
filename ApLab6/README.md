# ApLab6 — CRC Cards (Design Only)

Object-oriented design exercise using **CRC cards** (Class–Responsibility–Collaborator). This lab folder contains PDF design documents only—**no Java source code**.

Part of the [AUT AP Lab](../README.md) series.
